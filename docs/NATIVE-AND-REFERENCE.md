# Native与PyTorch参考实现及视频来源

## 两条路径执行同一个模型

MiniMax-H3 FL2VA是本项目的生成模型。Native是InfiniLM/InfiniCore适配执行路径，PyTorch参考是独立运行指定原始实现的对照路径。Qwen3-VL承担条件编码，H3 Transformer执行核心去噪计算，另有VAE等辅助模块。不能把“Native”解释成所有辅助模块都由本队从零实现，也不能把现有九齿安装/JIT成功解释成正式八卡生成已经调用九齿。

## 哪些配置相同 哪些差异仍需排查

输入、权重和生成参数相同不保证两条路径的所有内部实现与精度相同。已确认两侧Qwen实际输入张量及初始噪声一致；Qwen第50层输出仍有集中偏差。Native沿用了作业本地保留VAE必需FP32参数的变换，而原始参考入口有强制dtype转换；视频VAE264个、音频VAE832个参数项的精度审计差异已记录。参考入口保持未修改，没有据此断言这些差异解释了全部视频SSIM差距。

## 正确性与性能目标

先验证模型结构、装载、条件处理、算子、布局和多卡计算语义，再与指定参考比较输出规格、数值与视频相似度。目标是忠实实现指定模型，不是通过修改权重/输入/测试程序模仿某一段影片；不训练、微调或量化，不预计算或硬编码输出。合理浮点差异不要求文件哈希或逐像素相同。原始视频文件摘要用于证明材料来源，不作为图像生成质量阈值。

正确性满足要求后，再在相同输入、工作量、硬件和计时边界下验证算子、显存、传输与多卡调度收益。不能把参考529.569秒与Native801.070秒等不同放置/精度作业的原始阶段时间直接换算为正式加速比。
